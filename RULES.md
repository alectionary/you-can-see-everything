# Project rules — You Can See Anything teaser

These rules outrank any plan or brief. Every EDIT_PLAN and every QC checklist must
be audited against this file explicitly.

1. **No cut shorter than 2.0 seconds.** Every picture segment — shot, intertitle
   card, insert, panel composition, grid, black beat — lasts at least 2.000
   seconds. No exceptions unless Daniel explicitly requests one for a named
   segment. (Daniel, Oct 18, 2026. This generalizes his v5 note that sub-second
   cuts "seem like an accident." The v8/v9 breakdown plans violated it in many
   windows — card 1 ran 1.25s, several slivers ran 0.25s — because the rule was
   never written here and the plans were never audited against it.)
2. **Lengthening a beat extends the film.** Never fund a longer segment by
   shortening another one. Total runtime is flexible; the title chord strikes
   when it strikes. (Daniel, Oct 18, 2026, after v9 shortened the black beat
   from 1.0s to 0.5s to pay for a longer card 8.)
3. **Dialogue and subtitles are locked.** The v7 SRT is reused verbatim; dialogue
   stays at its recorded positions; subtitles transcribe the spoken words
   exactly; praise cards never overlap a speech window.
4. **Codex QC before delivery**, and the QC brief must include an explicit
   segment-duration audit against rule 1: every segment listed with its
   duration, minimum called out.
5. **Verify the rendered artifact**, not the sources: frames, pitch, levels and
   edit scans are measured on the final file the pipeline actually produced.
